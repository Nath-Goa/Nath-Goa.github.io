# nathank.me

Personal portfolio published through GitHub Pages at [nathank.me](https://nathank.me/).

- `index.html` contains the page content and project links.
- `styles.css` contains the layout and responsive styles.
- `motion.js` draws the seeded particle field and controls the scroll chapters and section arrows. The page provides a static layout when reduced motion is preferred or JavaScript is unavailable.

To preview locally, run `python -m http.server` from this directory and open the address it prints.
